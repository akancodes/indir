# UI reform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give indir filling cards coloured by file type, a quiet footer with a `⋯` menu, a window that uses its
size and remembers it, and an always-on-top mini strip.

**Architecture:** The page logic that can be tested without a window (type colour, fill, words, footer summary,
the strip's batch) moves into `ui/logic.js`, a classic script that is both a browser global and a CommonJS
module, tested with `node --test`. `app.js` keeps the DOM work. Mini mode is a second Tauri window (`mini`,
`ui/mini.html`) created hidden at start; Rust commands swap the two windows. `tauri-plugin-window-state`
remembers both windows.

**Tech Stack:** Tauri 2, Rust, vanilla HTML/CSS/JS (no build step), Node 22's built-in test runner.

**Spec:** `docs/superpowers/specs/2026-11-12-ui-reform-design.md`

## Global Constraints

- CSP stays `default-src 'self'; script-src 'self'; style-src 'self'; …`: no inline `<script>`/`<style>`, no
  `style=""` attributes in HTML; setting `node.style.x` from JS is allowed.
- `ui/` has no build step, no framework, no npm dependency at runtime.
- Engine (`engine/`) is untouched. Existing commands keep their names and arguments.
- Windows 10/11, macOS 11+, Linux (WebKitGTK); menus stay HTML in the window.
- Copy is English, sentence case, as today's wording where the spec doesn't change it.
- Default window 1000x680, min 480x360. Grid: new column once each can be ~420 px, cap 3, cards stretch.
- Mini strip ~320x90, always on top, no decorations, Ctrl/Cmd+M toggles it.
- Builds and GUI runs happen on render-01 in `indir-dev:local` (recipe: project memory `project_indir`), never on
  core-01; speed tests only against `cdn.kernel.org`, never in a loop.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`,
  `cargo test --workspace --locked`, `node --test tests/ui/` all pass.

## Review Focus

1. Very long file names (100+ chars, no spaces): the card must ellipsize, never push the percentage or buttons
   out or grow taller. → Task 2 preview fixture `long-name` + width check.
2. Unknown size (no Content-Length) while downloading: no percentage, a sheen, bytes so far; must not show `NaN%`
   or `Infinity`. → Task 1 `fillFraction` returns `null`; Task 2 fixture `no-size`.
3. Fill text contrast at 0% and 100% fill in both themes, for every type colour. → Task 2 step checking light and
   dark screenshots of fixtures at 0, 50, 100%.
4. The strip while a batch includes a download that is removed mid-batch: progress must not jump backwards or
   over 100%. → Task 1 test `batch: a removed download keeps what it added`, capped at 1.
5. A When done countdown starting while only the strip is shown: the main window must come back and take focus.
   → Task 5 GUI step on render-01.

### Task 1: Testable page logic

**Files:**
- Create: `ui/logic.js`, `tests/ui/logic.test.cjs`
- Modify: `ui/app.js` (use the moved helpers), `ui/index.html` (load `logic.js` before `app.js`),
  `.github/workflows/ci.yml` (a `node --test tests/ui/` step in the test job, Node 22 via `actions/setup-node`)

**Interfaces:**
- Produces, on `window.indirLogic` and `module.exports`:
  - `size(bytes: number) -> string`, `duration(seconds: number) -> string`, `badge(name: string) -> string`
    (moved unchanged from app.js)
  - `typeGroup(name: string) -> 'archive'|'disc'|'video'|'audio'|'app'|'document'|'other'` — extension, case
    insensitive; groups exactly as the spec lists (`AppImage` → app; `tar.gz`, `.tgz` → archive)
  - `fillFraction(item: View) -> number|null` — `done` → 1; size known → received/size clamped 0..1; else null
  - `cardWords(item: View) -> {main: string[], error: boolean}` — the line under the name. downloading:
    `['348 MB of 412 MB', '9.8 MB/s', '7 s left']` (no connections), `['Connecting…']` before bytes; queued:
    `['Waiting its turn']` (+ `of` when received); paused: `['Paused']` (+ `of`), or the starts-over sentence;
    failed: `[error || 'Stopped by a problem']`, error true; done: `[size, 'done 21:13']` using
    `finishedAt`
  - `summary(items: View[], speedLimit: number|null, whenDone: string) -> string` — today's footer words, plus
    `then sleep` / `then shut down` / `then quit` appended when `whenDone !== 'nothing'` and something is active
  - `nextBatch(batch: Batch|null, items: View[]) -> Batch` and `batchView(batch: Batch, items: View[]) ->
    {fraction: number|null, speed: number, eta: number|null, running: number, waiting: number, problem: boolean}`
    where `Batch = {ids: Set<number>, sizes: Map<number, number>, done: Map<number, number>}`

- [ ] **Step 1: Write the failing tests** in `tests/ui/logic.test.cjs` (`require('../../ui/logic.js')`):
  - `typeGroup`: `a.ZIP`→archive, `x.tar.gz`→archive, `u.iso`→disc, `m.MKV`→video, `s.flac`→audio,
    `k.AppImage`→app, `setup.exe`→app, `r.pdf`→document, `noext`→other, `.bashrc`→other
  - `fillFraction`: done with size null → 1; 50/100 → 0.5; received 150 size 100 → 1; size null downloading →
    null; size 0 → null
  - `cardWords`: downloading with connections 6 has no word containing `connection`; queued →
    `Waiting its turn`; failed with error `"404"` → `{main:['404'], error:true}`
  - `summary`: two downloading (speeds 1e6, 2e6) + one queued, whenDone `shutdown` →
    `'3.0 MB/s · 2 downloading · 1 waiting · then shut down'`; nothing active, whenDone `sleep`, items present →
    `'Nothing downloading'`
  - batch: starts with first active item; a finished item keeps its size counted (fraction stays ≥ previous);
    `a removed download keeps what it added`; fraction never > 1; size-unknown item adds nothing to total;
    all idle → `nextBatch` returns a fresh empty batch on the next active item; any `failed` in batch →
    `problem: true`
- [ ] **Step 2:** Run `node --test tests/ui/` — expected FAIL (`Cannot find module '../../ui/logic.js'`).
- [ ] **Step 3:** Implement `ui/logic.js` as `(function (root) { … const api = {…}; if (typeof module ===
  'object') module.exports = api; else root.indirLogic = api; })(this);` and switch app.js to it.
- [ ] **Step 4:** Run `node --test tests/ui/` — expected PASS, all tests.
- [ ] **Step 5:** Commit `UI: page logic in one tested file`.
